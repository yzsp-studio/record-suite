## 🇨🇳 中文

由 6 个技能组成的协作记录套件，覆盖云空间、日历、会议、知识库、多维表格和录音转写。lark-drive 管理云盘文件与文件夹的上传下载、复制移动、元数据、权限、版本和密级标签，还能把文件读取为 Markdown；lark-wiki 管理知识空间、空间成员与节点层级；lark-base 用多维表格搭台账、进度、订单、客户、排班等业务系统，支持多表联动、多视图、表单问卷、仪表盘、自动化工作流与行列权限。lark-calendar 负责日程的查看、搜索、创建、参会人管理、忙闲查询与会议室预定，lark-meeting 负责会议记录、纪要、逐字稿、妙记，以及进行中会议的实时问答、会中聊天和主持人管控。record 负责启动当前会话的录音，并在录音进行中回答关于录音内容的问题，几个技能按场景配合使用：先判断资源在云盘还是知识库，再决定录音、开会还是落表。

> ⚠️ **这是一套配合使用的技能组合（6 个）** —— 正文互相引用，建议成套取用。

### ✨ 能做什么

- lark-drive：上传下载、复制移动删除、查元数据与权限、看版本与密级标签、把 Drive 文件读取为 Markdown
- lark-base：用多维表格搭台账/进度/项目/订单/客户/排班系统，多表联动、多视图、仪表盘与自动化工作流
- lark-calendar：查看与搜索日程、创建更新会议、管理参会人、查忙闲并推荐时段、预定会议室
- lark-meeting：查会议纪要与逐字稿、搜索和编辑妙记、看进行中会议、发会中聊天、做主持人管控
- lark-wiki：创建知识空间、管理空间成员、维护节点层级、按 URL 路径和 token 路由而非按域名
- record：一句话启动录音，录音进行中即可就内容追问并拿到转写结果

## 🇬🇧 English

A six-skill collaboration and recording suite spanning cloud storage, calendar, meetings, knowledge base, multi-dimensional tables and recording transcription. lark-drive manages Drive files and folders — upload, download, create, copy, move, delete, metadata, permissions, versions and secure labels — and can fetch a Drive file as Markdown; lark-wiki manages knowledge spaces, members and node hierarchies; lark-base builds ledger, progress, project, order, customer and shift systems on bitable with linked tables, multiple views, forms, dashboards, automations and row/column permissions. lark-calendar handles viewing, searching, creating and updating events, attendee management, free/busy lookup, slot recommendation and meeting-room booking, while lark-meeting covers meeting records, minutes, transcripts, Minutes, live in-meeting Q&A, in-meeting chat and host controls. record starts recording for the current session and answers questions about what is being recorded, and the skills hand off to each other based on where the resource lives.

> ⚠️ **A cooperating suite of 6 skills** — they reference each other; use them as a group.

### ✨ What it does

- lark-drive: upload, download, copy, move, delete, read metadata and permissions, check versions and secure labels, and fetch Drive files as Markdown
- lark-base: build ledger, progress, project, order, customer and shift systems on bitable with linked tables, multiple views, dashboards and automations
- lark-calendar: view and search events, create and update meetings, manage attendees, check free/busy, recommend slots and book meeting rooms
- lark-meeting: read minutes and transcripts, search and edit Minutes, inspect in-progress meetings, send in-meeting chat and apply host controls
- lark-wiki: create knowledge spaces, manage members, maintain node hierarchies and route by URL path and token instead of by domain
- record: start recording with a single request, then ask about the content while recording is still running
